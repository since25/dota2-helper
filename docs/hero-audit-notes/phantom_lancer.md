## 技能复核

### Spirit Lance
- 中文名：灵魂之矛
- 当前模型：implemented / instant_fixed
- 本地 rawAttributes：`lance_damage=100/160/220/280`
- Dotabuff 对照：瞬时魔法伤害并产生幻象。
- 是否计入固定爆发：是
- 需要输入：无；若计算幻象追击则需要 `illusion_attack_count`
- 人工判断：直接伤害正确，但没有覆盖幻象后续输出。
- 问题记录：
  - 只算投矛伤害会低估长时间追击。
- 修正建议：
  - 直接伤害保持 instant；幻象输出单独进入 summons/illusion 层。

### Doppelganger
- 中文名：神行百变
- 当前模型：reference_only
- Dotabuff 对照：位移并产生幻象，不直接造成瞬时伤害。
- 是否计入固定爆发：否
- 需要输入：`illusion_attack_count`
- 人工判断：正确。它影响后续幻象输出窗口。
- 问题记录：
  - 幻象输出暂未建模。
- 修正建议：
  - 后续统一处理幻象攻击。

### Phantom Rush
- 中文名：幻影冲锋
- 当前模型：reference_only
- Dotabuff 对照：位移/敏捷或状态增益，不直接造成伤害。
- 是否计入固定爆发：否
- 需要输入：无
- 人工判断：正确。
- 问题记录：
  - 可能间接影响普攻伤害和接近能力。
- 修正建议：
  - 暂不进入固定爆发。

### Illusory Armaments
- 中文名：幻影军备
- 当前模型：ignored / reference
- Dotabuff 对照：幻象输出下限/增益，不直接造成伤害。
- 是否计入固定爆发：否
- 需要输入：无
- 人工判断：正确，但它是幻象层的重要修正。
- 问题记录：
  - 如果未来计算幻象伤害，需要读取该输出比例。
- 修正建议：
  - 进入 illusion modifier 层。

### Juxtapose
- 中文名：并列
- 当前模型：reference_only / proc
- Dotabuff 对照：攻击概率产生幻象，幻象有输出比例。
- 是否计入固定爆发：有条件计入后续普攻输出
- 需要输入：`attack_count`、`illusion_count`、`proc_mode`
- 人工判断：当前作为参考正确，但无法表达 PL 的核心持续输出。
- 问题记录：
  - 不应作为固定爆发；应作为概率生成幻象和幻象攻击伤害。
- 修正建议：
  - 后续做幻象系统时统一支持。
